# Chatbot 
A full-stack AI chatbot application built using LangChain, LangGraph, Flask, and Streamlit.
This project includes secure user authentication, conversational AI workflow management, and a clean interactive UI.

## ✨ Features
- User Signup & Login Authentication
- AI Chatbot using LangChain
- Workflow Management with LangGraph
- Streamlit Frontend Interface
- Flask Backend API
- JWT Authentication
- Conversation Memory Support
- Secure Password Hashing
